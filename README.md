# BrailleAtelier · 盲文教材转录和校对工具

BrailleAtelier 是一个完全运行在浏览器中的盲文教材工作台。它把课文原文逐行转换为盲文单元，允许编辑规则集、标记可疑规则、批量修正同类问题，并记录本地版本快照。

## 两侧各自维护

- **规范表归教研组**（`localStorage` 键 `sologsb-1010-spec-v1`）：条目（原文→盲文）、启停、可疑标记、规则集配置集中维护，带单调递增的修订号和变更流水。
- **课文稿归学校**（键 `sologsb-1010-braille-project-v2`）：学校维护课文原文、逐行校对状态与备注，并缓存一份规范规则视图，离线时照常用它转写。

### 规范条目改动如何联动课文行

- 条目一改动（盲文、启停、可疑、描述），引用它的课文行立即重算。
- 条目**换名**：旧名记入条目别名（`aliases`），引用旧名的行下次打开跟着重转。
- **两条并成一条**：被并条目立墓碑（`tombstoned`/`mergedInto`），旧引用沿墓碑重新归属到目标条目后重转。
- 已**批准/已校对**的行只有在重算结果确实变化时才**退回待核对**，校对备注原样保留并追加一行说明（日期 + 动了哪个条目），问题面板同时生成 `规范变动退回` 提醒；对账按变更流水幂等，不重复退回、不重复写备注。

### 旧稿升级与容错

- v1 旧稿（无规范归属字段）打开时自动升级：按规范表为缓存规则和 token 补 `specEntryId` 归属（含别名/墓碑追溯），学校自定义条目补录进规范表，原校对备注保留。
- 规范表读不出来（损坏/存储被禁）时课文稿照常编辑保存，规范条目面板锁定只读并提示。
- 保存采用 `.pending → .backup → 主键` 的提交流程：失败时上一版不被破坏；学校稿保存失败会按指数退避自动重试，也可手动重试，浏览器重新在线时自动再存。

## 功能

- 课文拆分：粘贴整篇课文后按换行和句末标点自动拆行，也可手动新增、编辑、拆分或删除行。
- 多规则集：内置 UEB 教学规则、通用文学盲文和逐字拼读三套规则，可即时切换。
- 转写模型：支持字母、数字、标点、词级缩写、分词空格和跨行连字符；每个盲文单元都带规范条目归属。
- 逐行校对：每行同时显示原文、拆分后的盲文单元、可疑项和校对状态。
- 问题处理：按同类规范条目聚合问题，可停用条目并批量修正全部受影响行。
- 规范条目：右侧"规范条目"页支持修订、标记可疑、新增、删除以及两条合并；所有动作留痕并触发对账。
- 键盘操作：`⌘/Ctrl + Z` 撤销、`⇧⌘/Ctrl + Z` 重做、`⌘/Ctrl + Enter` 批准并进入下一行、`J/K` 或上下方向键切换行。
- 版本与导出：最多保留 20 个浏览器本地版本，可恢复版本；支持文本导出和打印版导出。
- 本地持久化：规范表与课文稿分开存储，刷新或离线后继续编辑。

## 测试

核心联动逻辑有不依赖浏览器的场景测试（Node + esbuild）：

```bash
npm test
```

覆盖：条目改动重算与批准行退回、换名/并条的别名与墓碑重归属、v1 旧稿升级、对账幂等、规范表离线、损坏备份回退、保存失败保留上一版、打开时按修订号对账。

## 技术栈

- Preact 10
- TypeScript 5
- Material Web Components 2
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认监听 Vite 的 `5173` 端口。项目没有硬编码宿主端口。

## 构建

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。类型检查由构建命令自动执行。

## Docker

```bash
docker build -t sologsb-1010 .
docker run --rm -p 10010:80 sologsb-1010
```

容器内部由 nginx 监听 `80`；宿主端口按根项目端口表映射为 `10010`。
