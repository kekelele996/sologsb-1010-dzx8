# BrailleAtelier · 盲文教材转录和校对工具

BrailleAtelier 是一个完全运行在浏览器中的盲文教材工作台。它把课文原文逐行转换为盲文单元，允许编辑规范条目、标记可疑条目、批量修正同类问题，并记录本地版本快照。

## 功能

- 课文拆分：粘贴整篇课文后按换行和句末标点自动拆行，也可手动新增、编辑、拆分或删除行。
- 多规范表：内置 UEB 教学规则、通用文学盲文和逐字拼读三套规范表，可即时切换。
- 转写模型：支持字母、数字、标点、词级缩写、分词空格和跨行连字符。
- 逐行校对：每行同时显示原文、拆分后的盲文单元、可疑项和校对状态。
- 问题处理：按同类条目聚合问题，可停用问题条目并批量修正全部受影响行。
- 分离维护：规范表归教研组、课文稿归学校，两份数据各自独立保存、互不覆盖。
- 条目变更联动：规范条目一改动，用过它的课文行自动重算；条目换名或两条并成一条，引用它的行下次打开跟着重转；已批准的行结果变了就退回待核对，并在行备注和问题区写明动了哪个条目。
- 条目编辑：启停缩写、修改原文与输出（自动升版本）、标记可疑、新增自定义条目、两条并成一条（旧引用按别名自动迁移）。
- 旧稿升级：旧版合并存储的稿子打开时自动拆分升级，按规范表补齐行归属，旧校对备注原样保留。
- 容错：规范表读不出来时课文稿照旧能编辑保存；课文稿保存失败会按学校侧自动重试，上一版始终保留，也可手动重试。
- 键盘操作：`⌘/Ctrl + Z` 撤销、`⇧⌘/Ctrl + Z` 重做、`⌘/Ctrl + Enter` 批准并进入下一行、`J/K` 或上下方向键切换行。
- 版本与导出：最多保留 20 个浏览器本地版本，恢复版本时按现行规范表重新核对；支持文本导出和打印版导出。
- 本地持久化：刷新或离线后继续编辑，规范表与课文稿分别保存在 `localStorage` 的两个键下。

## 技术栈

- Preact 10
- TypeScript 5
- Material Web Components 2
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认监听 Vite 的 `5173` 端口。项目没有硬编码宿主端口。

## 测试

```bash
npm test
```

场景测试覆盖：条目改动后引用行重算与批准行退回、换名/合并后下次打开重转、旧稿升级与备注兼容、规范表读取失败降级、保存失败重试与上一版保留。

## 构建

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。类型检查由构建命令自动执行。

## Docker

```bash
docker build -t sologsb-1010 .
docker run --rm -p 10010:80 sologsb-1010
```

容器内部由 nginx 监听 `80`；宿主端口按根项目端口表映射为 `10010`。
